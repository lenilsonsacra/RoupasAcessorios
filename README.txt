VÉRTICE STORE — site demonstrativo HTML, CSS e JavaScript

COMO EXECUTAR
1. Extraia a pasta vertice-store.
2. Abra a pasta no VS Code (Arquivo > Abrir Pasta).
3. Abra index.html no navegador ou use a extensão Live Server.

PERSONALIZAR WHATSAPP
Abra js/script.js e procure WHATSAPP_NUMBER no início do arquivo. Troque 5500000000000 pelo número da loja com código do país e DDD, apenas números. Exemplo de formato: 55 + DDD + número.

PERSONALIZAR PRODUTOS
No arquivo js/script.js, edite o array products: name (nome), category (roupas/calcados/acessorios), price (preço), oldPrice (preço antigo ou null), tag, image (URL da imagem) e colors.

IMAGENS
As imagens de demonstração usam URLs do Unsplash e precisam de internet. Para usar imagens próprias, coloque os arquivos em img/produtos/ e troque image por caminhos como img/produtos/camiseta.jpg.

OBSERVAÇÕES
- Carrinho e filtros funcionam no navegador.
- O pedido é montado e enviado para o WhatsApp da loja. O cliente combina pagamento e entrega diretamente com a loja.
- O formulário de newsletter é apenas demonstrativo; não salva e-mails sem integração com um serviço.
- Preços, estoque, imagens e número de WhatsApp são dados fictícios/de exemplo.
